# 🥔 PataMati2 — El Comandante Patata V2

Juego web cooperativo para jugar con Mati. ¡Defended la huerta de los vegetales rebeldes!

## Cómo jugar

**Opción rápida:** abrí `comandante-patata.html` con doble clic (un solo archivo, no necesita servidor).

**Opción desarrollo:** abrí `index.html` con un servidor local.

## Controles

| Jugador | Mover | Disparar |
|---------|-------|----------|
| **Comandante Patata** 🥔 | `W` `A` `S` `D` | `Espacio` |
| **Mati** 🧒 | `↑` `←` `↓` `→` | `Enter` |

## Novedades V2

- **Agujeros de teletransporte:** 3 pares de portales en la huerta. Al entrar en uno, salís por el otro del par.
- Oleadas de enemigos vegetales
- Power-ups: vida, disparo rápido, escudo
- Modo solo y modo 2 jugadores
